# 构建环境与版本锁定

> 本机容器环境（Ubuntu 24.04 aarch64，运行于 Android 设备内）。修改版本前先读本文。

## 关键约束

1. **aapt2 必须用 arm64 版**：Google 官方 build-tools 只提供 linux-x86_64，直接使用会报 `cannot execute binary file`。项目通过 `gradle.properties` 的 `android.aapt2FromMavenOverride` 指向 `tools/aapt2/aapt2` 包装脚本。
2. **不要全局导出 `LD_LIBRARY_PATH`**：aapt2 依赖 Termux 的 bionic 库（`/opt/toolchain/termux-libs`），但该路径会污染 glibc 程序（java/python 全部崩溃）。只在 `tools/aapt2/aapt2` 包装脚本内部设置。
3. **必须设置 UTF-8**：项目路径含中文，JDK 默认编码不是 UTF-8 时 Gradle 会抛 `InvalidPathException`。`tools/env.sh` 已设置 `LANG=C.UTF-8`、`LC_ALL=C.UTF-8`、`JAVA_TOOL_OPTIONS=-Dfile.encoding=UTF-8`。
4. **内存限制**：容器可用内存约 2.4 GB，`gradle.properties` 固定 `-Xmx1536m`、`workers.max=2`、关闭并行。
5. **国内镜像**：Maven 走阿里云（`settings.gradle.kts`），Gradle 发行版走腾讯镜像。

## 构建命令

```bash
source tools/env.sh
cd app
gradle --no-daemon --console=plain assembleDebug
# 或
scripts/build.sh assembleDebug
```

产物：`app/app/build/outputs/apk/debug/app-debug.apk`
