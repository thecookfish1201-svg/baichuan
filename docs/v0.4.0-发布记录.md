## 3. 本版交付内容（摘要）

- 单一聊天 UI；删除 DeepSeek 式独立页面与外观选项；旧设置自动迁移
- Composer 单状态源；regenerate/editAndResend 防重入；准备/流式均可停止
- 消息树校验与级联删除；role 序列校验；图片-only 保留
- reasoning 原文退出 UI；统一 Markdown；错误文案与诊断分离
- Agent 工具执行暂停（服务层开关 + UI 入口移除，数据保留）
- 搜索/深度思考迁入统一输入区；发现占位页下架；关于页接通
- 云端 TTS：失败可见、异步播放、WAV 头修复、计费字符截断、配置状态提示

详细变更见 `CHANGELOG.md` 的 `[0.4.0]`。
