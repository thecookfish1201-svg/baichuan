# 百川 DeepSeek 风格落地规范

> 版本：v1.0 · 2026-11-07
> 编写：鲸鱼娘（美术与视觉协作）
> 依据：阶段二验收对比截图四张——我们的 DeepSeek 风格实现、我们的微信风格实现、官方 DeepSeek APP 浅色、官方 DeepSeek APP 深色。
> 关系：本文件是《视觉规范.md》的 DeepSeek 风格细则，细化并修正其中 DeepSeek 部分；两者冲突时，DeepSeek 风格以本文件为准（例如用户气泡颜色）。
> 约束：只定义视觉与交互规格，不改 `app/` 下任何代码。

---

## 0. 一句话结论

官方 DeepSeek 的聊天页不是「白底版的微信」：它**没有气泡壳、没有头像、没有分割线**，靠「大留白 + 思考轨 + 操作栏 + 大圆角输入卡」建立识别度。我们当前的实现保留了微信式的顶栏、绿色气泡、输入栏和分支浮层，所以看起来只是换了背景色的微信。

## 1. 现状差距对照

| 验收点 | 官方（图三/图四） | 我们的实现（图一） | 判定与处理 |
|---|---|---|---|
| 顶栏 | 左侧菜单、标题左对齐、右侧通话/静音/新建，无分割线 | 返回箭头、标题居中、底部分割线 | 不符，必须改 |
| 页面背景 | 纯白 `#FFFFFF` / 近黑 `#121212` | 浅灰 `#F2F2F2` 左右 | 不符，改纯白/近黑 |
| 用户消息 | 浅蓝灰气泡 `#E8EEFB`（深色深灰 `#2A2A2A`） | 微信绿气泡 | 不符，必须改 |
| AI 回复 | 无壳正文，17sp 大行高 | 无壳正文，但字号行高偏小 | 部分符合，调排版 |

| 操作栏 | 复制、赞、踩、朗读、分享 + 右侧重新生成 | 完全没有 | 缺失，必须做（朗读可隐藏） |
| 分支切换 | 无浮层 | 用户消息下「< 2/2 >」白框按钮 | 不符，移除浮层，改到长按菜单 |

| 底部小字 | 「回答由 AI 生成，仅供参考」 | 无 | 缺失，必须做 |
| 头像与名称 | 不显示 | 不显示（正确） | 符合 |

> 注意：图二（微信风格）里的绿色气泡、白色 AI 气泡、居中标题、输入栏都是微信式的**正确**表现，不应拿它当 DeepSeek 风格的基础；两套风格必须由不同的布局组件实现，而不是同一套组件换颜色。

## 2. 页面结构总览

```
┌──────────────────────────────────────┐
│ 状态栏（透明，图标随主题反色）        │
├──────────────────────────────────────┤
│ 顶栏 56dp：菜单 24 | 标题 17 左对齐 | 右 3 图标 │
├──────────────────────────────────────┤
│ 消息区（可滚动，左右 20dp）           │
│   · 用户气泡（右，浅蓝灰，20dp 圆角）  │
│   · 思考折叠行 17sp 灰               │
│   · 思考轨（2dp 竖线 + 4dp 圆点）     │
│   · AI 正文 17sp/1.75                │
│   · 操作栏（5 图标 + 右侧刷新）        │
│   · 消息间距 24dp                    │
├──────────────────────────────────────┤
│ 输入卡（左右 16dp，26dp 圆角）        │
│   第一行：占位/输入 17sp              │
│   第二行：胶囊 ×2 + 右侧 + / 语音     │
├──────────────────────────────────────┤
│ 底部小字 11sp 居中（键盘弹出时隐藏）   │
└──────────────────────────────────────┘
```

- 屏幕逻辑宽度按 411dp 设计（1080px / 2.625）。
- 页面不允许出现：分割线、卡片阴影分区、居中大标题、头像、名称、时间戳、绿色气泡。
- 表情符号只允许出现在**消息内容**里，不允许作为 UI 图标。

## 3. 顶栏

| 项 | 规格 |
|---|---|
| 高度 | 56dp（不含状态栏），状态栏用 `WindowInsets` |
| 背景 | `#FFFFFF` / `#121212`，与页面同色，**无分割线、无阴影** |
| 左侧图标 | `menu` 24dp，热区 40×40dp，距左 12dp |
| 标题 | 17sp / 22dp 行高，Medium，`#121212` / `#ECECEC`；距菜单 8dp，左对齐，单行超长省略 |
| 右侧图标 | `add_circle` 24dp（必须）、`volume_off` 24dp（可选）、`call` 24dp（第一版不做） |
| 右侧排布 | 图标间距 8dp，热区 40×40dp，最后一个距右 16dp |
| 点击行为 | 菜单：打开左侧会话抽屉（宽 296dp，遮罩 32% 黑）；无多会话时可改为返回 |
| 状态栏 | 透明，图标深色/浅色随主题；不叠加毛玻璃 |

第一版取舍：

- **必须**：菜单（或返回）、左对齐标题、新建对话。
- **可选**：静音（无 TTS 时可先隐藏，不要放灰色无效图标）。
- **不做**：通话、视频通话，入口直接不渲染。

## 5. 思考面板（重点）

### 5.1 折叠行（始终可见的标题行）

| 项 | 规格 |
|---|---|
| 文案 | 生成中：「思考中（2 秒）」；完成：「已思考（用时 2 秒）」 |
| 字号 / 行高 | 17sp / 24dp，Regular |
| 颜色 | `#8C8C8C`（浅） / `#8A8A8A`（深） |
| 箭头 | `chevron_down` 20dp，颜色同文字，与文字间距 4dp |
| 行高 / 热区 | 内容行 28dp；整行可点，热区高 48dp、宽 = 正文宽 |
| 左边距 | 20dp（与正文对齐，不缩进） |
| 上间距 | 距用户气泡 / 上一条消息 20dp |
| 下间距 | 展开时 12dp 到思考轨；折叠时 20dp 到正文 |
| 展开状态 | 箭头旋转 180°；折叠时箭头朝下 |
| 动画 | 150ms 旋转、180ms 高度动画；低端机直接切换，无动画 |

用时格式：

- 小于 60 秒：`用时 N 秒`。
- 60 秒及以上：`用时 N 分 M 秒`。
- 无计时数据：只显示「已思考」，括号整体省略。
- 思考中断或失败：显示「思考中断」+ `error` 图标 16dp，颜色 `#FA5151`；点开显示已生成的部分。

### 5.2 展开态：思考轨

结构：左侧一条竖线贯穿思考内容，首行左上角一个圆点，右侧是灰色正文。

| 项 | 规格 |
|---|---|
| 竖线宽度 | 2dp |
| 竖线颜色 | `#E5E5E5`（浅） / `#333333`（深） |
| 竖线位置 | 屏幕左 28dp（正文左边距 20dp + 8dp） |
| 竖线范围 | 从首行圆点中心开始，到思考文字最后一行下方 4dp 结束 |
| 圆点 | 直径 4dp，`#C4C4C4`（浅） / `#666666`（深），圆心在竖线顶端 |
| 文字左边距 | 屏幕左 36dp（距竖线 8dp） |
| 文字右边距 | 屏幕右 20dp |
| 字号 / 行高 | 15sp / 26dp（1.73×） |
| 文字颜色 | `#9A9A9A`（浅） / `#A0A0A0`（深） |
| 段间距 | 12dp |
| 最大高度 | 不设内部滚动，整段展开随页面滚动；内容过长由用户手动折叠 |
| 选中 | 思考文字可选择复制（与正文一致） |

### 5.3 展开 / 折叠行为

1. 默认展开：正在生成、刚生成完成、以及当前会话最近 3 条 AI 回复默认展开；更早的默认折叠，避免整屏灰色文字。
2. 点击折叠行任意位置切换；同一消息的展开状态独立保存，切换会话或重新进入后保留。
3. 折叠只影响显示，不删除思考内容；折叠后仍可在详情中查看（第一版可只保留展开状态）。
4. 生成中强制展开，用户手动折叠后不再自动展开（避免和用户抢控制权）。
5. 用户上滑查看历史时暂停自动跟随，不强行滚到底部。
6. 模型不返回思考内容、或用户关闭「深度思考」时，整块隐藏，不留空行和占位。
7. 思考内容不做打字机动画，按增量整段刷新；避免低端机每帧重排。

### 5.4 与正文的层级关系

- 思考是过程，正文是结果：思考文字一律比正文小 2sp、灰一档，禁止与正文同色同字号。
- 思考内容不参与操作栏（复制/分享只针对正文）。
- 思考块与正文之间的间距 20dp；不使用分割线。

## 6. AI 回复正文与操作栏

### 6.1 正文

| 项 | 规格 |
|---|---|
| 对齐 | 左对齐，无气泡、无背景、无边框 |
| 左右边距 | 20dp |
| 字号 / 行高 | 17sp / 30dp（约 1.75×） |
| 颜色 | `#1A1A1A`（浅） / `#E8E8E8`（深） |
| 段间距 | 16dp |
| 列表 | 左缩进 20dp，项间距 8dp，圆点与文字间距 8dp |
| 引用 | 左侧 2dp `#E5E5E5` 竖线，文字 `#6B6B6B` |
| 代码块 | 背景 `#F6F7F9` / `#1F2023`，圆角 12dp，内边距 12dp，等宽 14sp/1.5，横向滚动 |
| 行内代码 | 背景 `#F2F3F5` / `#26282C`，圆角 4dp，内边距 2dp×4dp |
| 与操作栏间距 | 正文结束到操作栏 12dp |
| 流式光标 | 末尾 2dp×17sp 竖条，`#4D6BFE`，闪烁 1 秒/次 |

### 6.2 操作栏

顺序（从左到右，官方同款）：

| 序号 | 功能 | 图标（Material Symbols） | 状态 |
|---|---|---|---|
| 1 | 复制 | `content_copy` | 点击复制 Markdown 原文，Toast「已复制」 |
| 2 | 点赞 | `thumb_up` | 选中变 Filled + 品牌蓝；与点踩互斥 |
| 3 | 点踩 | `thumb_down` | 选中变 Filled + 品牌蓝；与点赞互斥 |
| 4 | 朗读 | `volume_up` | 第一版隐藏（见第 9 章） |
| 5 | 分享 | `share` | 系统分享纯文本 |
| — | 弹性空白 | — | 把重新生成推到右侧 |
| 6 | 重新生成 | `refresh` | 右对齐，点击后整条回复重新生成 |

| 项 | 规格 |
|---|---|
| 图标尺寸 | 22dp |
| 触控热区 | 40×40dp |
| 相邻热区间距 | 4dp（视觉间距约 18dp，中心距 44dp） |
| 行高 | 40dp |
| 左起 | 20dp，与正文对齐 |
| 右端重新生成 | 距右 20dp |
| 图标颜色 | `#6B6B6B`（浅） / `#8A8A8A`（深） |
| 选中颜色 | `#4D6BFE`（浅） / `#7C93FF`（深） |
| 出现时机 | 回答完成后淡入 120ms；流式生成中不显示 |
| 生成中替代 | 操作栏位置显示「停止生成」按钮（`stop_circle` + 文字 14sp），点击中断流式输出 |
| 无障碍 | 每个图标必须有 contentDescription；40dp 热区不得缩小 |

第一版可以只做 4 个必需图标（复制、赞、踩、重新生成）加分享；朗读在未配置 TTS 时**隐藏**而不是置灰，避免出现点了没反应的入口。

### 6.3 重新生成与分支

- 官方没有「2/2」这类浮层；我们图一里用户气泡下的白色「< 2/2 >」必须移除。
- 分支切换改为：长按消息 → 菜单「上一版本 / 下一版本」，或长按「重新生成」弹出历史版本列表。
- 分支切换入口不占用正文与操作栏的视觉空间。
- 重新生成产生新分支时，原回复保留，不覆盖；旧分支通过长按菜单访问。
- **与阶段二验收清单的关系**：清单里「出现分支切换器（‹ 1/2 ›）」描述的是微信式风格。功能不减，只是入口不同——微信式继续显示分支切换器（建议放在回复下方左侧，而不是挂在用户消息下），DeepSeek 式不显示浮层、改到长按菜单。两套风格共用同一套分支数据。

## 7. 输入区

### 7.1 输入卡片

| 项 | 浅色 | 深色 |
|---|---|---|
| 外边距 | 左右 16dp，距底部小字 8dp | 同左 |
| 背景 | `#FFFFFF` | `#1F1F1F` |

### 7.2 胶囊按钮（输入行下方）

| 项 | 规格 |
|---|---|
| 数量 | 2 个：「深度思考」「智能搜索」 |
| 高度 | 32dp |
| 圆角 | 16dp（胶囊） |
| 内边距 | 水平 12dp |
| 图标 | 16dp；「深度思考」`psychology`，「智能搜索」`language` |
| 图标与文字间距 | 6dp |
| 字号 / 字重 | 14sp / Medium |
| 两个胶囊间距 | 8dp |
| 位置 | 输入行下方 10dp，左对齐 16dp |
| 关闭态背景 | `#EDF2FF`（浅） / `#1E2A4A`（深） |
| 关闭态文字/图标 | `#4D6BFE`（浅） / `#7C93FF`（深） |
| 开启态背景 | `#4D6BFE` / `#3D5BD9` |
| 开启态文字/图标 | `#FFFFFF` / `#E8ECFF` |
| 禁用态 | 背景 `#F4F5F7` / `#24262A`，文字 `#A3A3A3` / `#6E6E6E`，点击弹说明，不静默失效 |
| 点击行为 | 切换开启状态；开启后本次及后续消息带上对应参数 |

说明：

- 「深度思考」在所选模型不支持推理时置为禁用，并提示「当前模型不支持深度思考」。
- 「智能搜索」在未配置搜索服务时置为禁用，并提示「未配置搜索服务，可在设置中开启」。
- 胶囊只在输入区出现，不在消息区重复显示。
- 胶囊上的开关状态变化不应触发布局跳动（图标固定 16dp、文字固定 14sp）。

### 7.3 右侧按钮

| 项 | 规格 |
|---|---|
| 按钮 | `add_circle`（附件）与 `mic`（语音），各 32dp 圆形，图标 24dp |
| 位置 | 胶囊行右侧，距右 16dp；两者间距 4dp |
| 热区 | 40×40dp |
| 颜色 | 图标 `#121212` / `#ECECEC`；圆形描边 1.5dp 同色（官方为白底黑描边圆） |
| 附件面板 | 点击加号从底部弹出，2 行 4 列，图标 24dp + 文字 12sp |
| 语音 | 第一版未接入语音输入时隐藏；接入后长按说话、松开发送 |

### 7.4 发送状态

- 输入为空：右侧显示 `add_circle` 与 `mic`。
- 输入非空：右侧收起上述按钮，出现 32dp 圆形发送键，背景 `#4D6BFE`（深色 `#7C93FF`），图标 `arrow_upward` 20dp，颜色 `#FFFFFF`（深色 `#0B0F1A`）。
- 生成中：发送键变为停止键（`stop_circle`），点击中断。
- 键盘弹出：输入卡上移到键盘上方 8dp，底部小字隐藏；消息列表滚动到底部。

### 7.5 底部小字

| 项 | 规格 |
|---|---|
| 文案 | 「回答由 AI 生成，仅供参考」 |
| 字号 | 11sp / 15dp |
| 颜色 | `#A8A8A8`（浅） / `#6B6B6B`（深） |
| 位置 | 输入卡下方 8dp，水平居中 |
| 底部安全区 | 距系统导航栏 8dp |
| 行为 | 不可点击、不可被内容遮挡；键盘弹出时可暂时隐藏 |
| 文案变更 | 只允许项目方统一修改，不随会话变化 |

## 9. 第一版范围：必须做、可做、不做

### 9.1 必须做（阶段二验收硬指标）

| 项 | 说明 |
|---|---|
| 纯白/近黑背景 + 无分割线 | 去掉微信式的浅灰页面与顶栏分割线 |
| 官方式顶栏 | 菜单/返回 + 左对齐标题 + 新建；无通话 |
| 浅蓝灰用户气泡 | 替换微信绿；深色用深灰 |
| 思考折叠行 | 计时文案、箭头、点击展开/折叠、默认展开策略 |
| 思考轨 | 2dp 竖线 + 4dp 圆点 + 15sp 灰色文字；无思考时整块隐藏 |
| 操作栏 | 复制、赞、踩、分享、重新生成；40dp 热区、22dp 图标 |
| 输入大卡片 | 26dp 圆角、白底/深灰底、描边与轻阴影 |
| 两个胶囊 | 深度思考、智能搜索，含开/关/禁用三态与说明 |
| 底部小字 | 「回答由 AI 生成，仅供参考」，11sp 居中 |
| 移除「2/2」浮层 | 分支切换到长按菜单 |
| 流式状态 | 停止生成按钮、思考计时、正文光标 |

### 9.2 可做（视阶段二进度）

| 项 | 处理 |
|---|---|
| 分享 | 系统分享，成本低，建议做 |
| 思考内容选择复制 | 与正文一致，顺手实现 |
| 消息长按菜单 | 复制、编辑、删除、分支切换、查看时间 |
| 附件面板 | 保留图片/文件两项，去掉不支持的入口 |
| 语音入口 | 未接入前隐藏，不放置灰按钮 |
| 顶栏静音 | 仅当有朗读/通知能力时显示 |

### 9.3 第一版不做

| 项 | 理由与处理 |
|---|---|
| 通话、视频通话 | 总提示词没有要求；入口不渲染，不做灰按钮 |
| 朗读（TTS） | 依赖阶段三的 TTS 配置；未配置时隐藏，后续接入再显示 `volume_up` |
| 思考过程的打字机动画 | 低端机重排成本高，改整段刷新 |
| 思考内容内部滚动 | 避免嵌套滚动，整段展开 + 手动折叠 |
| 点赞点踩上报服务端 | 第一版只做本地状态，不承诺反馈 |
| 搜索来源卡片/引用列表 | 第一版只做智能搜索开关与结果文本，来源展示后置 |
| 会话侧栏完整实现 | 菜单可先打开已有会话列表抽屉，不复刻官方全部侧栏 |
| 拍照、实时语音、通话摘要 | 不属于第一版范围 |

## 10. 验收清单（照图逐项核对）

- [ ] 页面背景纯白/近黑，聊天区无浅灰色块、无分割线。
- [ ] 顶栏：左侧菜单，标题 17sp 左对齐，右侧新建；无居中标题；无通话入口。
- [ ] 用户消息：浅蓝灰 `#E8EEFB` 圆角气泡，右对齐，80% 最大宽；无微信绿。
- [ ] 有思考时显示「已思考（用时 N 秒）」；点击可折叠/展开，箭头旋转。
- [ ] 思考内容：左侧 2dp 竖线、首行 4dp 圆点、15sp 灰色文字，右边距 20dp。
- [ ] 无思考内容时整块隐藏，不留空白。
- [ ] AI 正文无气泡壳，17sp、行高约 30dp，左右 20dp。
- [ ] 操作栏：复制、赞、踩、分享在左，重新生成在右；图标 22dp、热区 40dp；生成中隐藏。
- [ ] 输入卡：26dp 圆角、白底、细描边、轻阴影，内含两行结构。
- [ ] 胶囊：32dp 高、16dp 圆角、浅蓝底蓝字，关闭/开启/禁用三态清楚。
- [ ] 底部小字存在且居中，键盘弹出时隐藏。
- [ ] 用户气泡下没有「2/2」浮层；分支切换在长按菜单。
- [ ] 深色模式逐项对照第 8 章，用户气泡为深灰不是深蓝。
- [ ] 系统字号放大 1.3 倍时，顶栏标题、思考行、胶囊文字不截断。
- [ ] 无 Emoji 作为 UI 图标；操作栏、胶囊、顶栏图标均来自统一图标库。
