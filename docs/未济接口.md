# 未济接口 · 插件协议 v1（筹备稿）

> 未济接口是百川的长期扩展协议，负责内部插件的安装、启用、停用、卸载与数据隔离。
> 与 MCP 是两套体系：未济管内部插件生命周期，MCP 连外部工具与服务。
> 本文是阶段五实施前的设计稿，协议细节在实现时以本文为准。

## 1. 插件包结构

```
plugin.zip
├── manifest.json        # 必备，插件声明
├── config/              # 配置型插件资源（主题、角色卡、提示词、预设）
│   └── ...
└── code/                # 代码型插件入口（第一版不开放）
```

## 2. manifest.json

```json
{
  "id": "com.tongzhouweiji.theme.dark",
  "name": "示例主题",
  "author": "作者",
  "version": "1.0.0",
  "apiVersion": "1.0",
  "type": "config",
  "dependencies": [],
  "permissions": ["theme.apply"],
  "dataSpace": "isolated"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 全局唯一，建议反向域名 |
| name / author / version | 是 | 展示与版本管理 |
| apiVersion | 是 | 语义化版本，如 `1.0` |
| type | 是 | `config`（配置型）或 `code`（代码型，第一版不执行） |
| dependencies | 否 | 依赖的插件 id 与版本范围 |
| permissions | 是 | 所需权限，未授权则不启用 |
| dataSpace | 否 | 默认 `isolated`，插件数据在独立目录 |

## 3. 权限清单（第一版）

| 权限 | 作用 | 说明 |
|---|---|---|
| `theme.apply` | 应用主题/外观 | 只能修改主题令牌，不能读聊天内容 |
| `prompt.read` | 读取智能体提示词 | 需要用户确认 |
| `prompt.write` | 写入人设/预设 | 需要用户确认 |
| `data.read` | 读取插件自己空间的数据 | 不能读核心库 |
| `data.write` | 写入插件自己空间的数据 | 不能写核心库 |
| `network` | 访问网络 | 需要用户确认，且记录调用 |

原则：插件只能访问用户授权的资源；未声明权限的调用直接拒绝并记录。

## 4. 生命周期

1. **安装**：校验 manifest → 检查 apiVersion 兼容 → 展示权限清单 → 用户确认 → 解包到私有目录 → 写入 plugins 表（state=installed）。
2. **启用**：检查权限授权状态 → 加载配置型资源 → state=enabled。
3. **停用**：释放资源 → state=disabled；数据保留。
4. **卸载**：明确区分「仅卸载」与「卸载并删除数据」两个动作；后者需要二次确认。
5. **更新**：保留上一版本包与数据快照；新版加载失败时回滚到旧版本并提示。

## 5. 数据空间

- 每个插件独立目录：`files/plugins/<pluginId>/`。
- 插件数据不进入核心库 `baichuan.db`，避免插件异常影响主聊天。
- 备份时作为独立类别打包（`plugin_store` 目录 + 配置清单）。

## 6. 版本兼容

- `apiVersion` 按主版本号判断：`1.x` 插件可被 `1.y` 客户端加载；`2.x` 需要明确兼容声明。
- 不兼容时明确提示「插件需要未济接口 2.0，当前 1.0」，不静默失败。

## 7. 异常隔离

- 插件加载/执行异常只影响该插件，主聊天不受影响。
- 记录错误到插件自己的日志，不写核心错误事件表（或只写摘要）。
- 插件崩溃后自动停用，提示用户查看原因。

## 8. 内部测试插件

第一版必须制作一个不对外发布的测试插件，覆盖：

- 安装 / 启用 / 停用 / 卸载
- 权限拒绝（未授权时拒绝加载）
- 数据读写（独立目录）
- 异常隔离（模拟崩溃，主聊天不受影响）
- 版本兼容（apiVersion 不匹配时提示）

## 9. 第一版范围

- 配置型插件：主题、角色卡、提示词、预设的导入与启用。
- 代码型插件：只完成协议定义与安全评估，不实现执行环境。
- 不开发朋友圈、表情包、桌宠等官方插件功能，只预留接入能力。
