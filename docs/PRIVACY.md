# 隐私说明

百川是本地优先的客户端，项目方不提供、也不要求使用云端服务器。

## 数据存储

- 聊天记录、智能体配置、记忆、附件、插件数据全部保存在设备本地。
- 模型 API Key 使用 Android Keystore 加密存储，不落明文。
- 项目方不收集、不上传任何用户数据。

## 网络请求

应用只在你配置的服务与功能触发时发起网络请求：

- 你配置的模型服务商（聊天、压缩、Agent 规划）
- 你配置的搜索服务（DeepSeek 官方 Search 或自定义服务）
- 你配置的 MCP 服务器（连接与工具清单）
- 插件声明的网络权限（需你授权）

请求内容取决于功能与你的配置，项目方无法读取。

## 备份

- 备份文件由你选择保存位置，项目方不参与传输。
- 备份不包含 API Key 明文，恢复后需重新填写。
- 备份内含完整性校验信息，不包含遥测数据。

## 删除

- 删除聊天、智能体、插件数据、备份文件均由你操作。
- 卸载应用会删除应用私有目录数据（系统行为）。

## 第三方

- 模型与搜索服务由你自行选择，其数据处理遵循对应服务商条款。
- 应用内不集成广告、统计或推送 SDK。
