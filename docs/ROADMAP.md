# 路线图

> 路线：A —— 个人 AI 对话工作台。产品边界以《百川·产品章程 v1.0》为准。
> 版本目标是交付边界，不是强制日期；不得以「功能已接入」代替「用户能稳定使用」。

## v0.4.0（当前，核心对话与体验收敛）

- 单一聊天 UI 与统一 Composer，移除 DeepSeek 式独立页面
- Composer 单状态源：发送、准备、流式、停止、失败、取消互斥可预测
- 消息树级联删除、分支完整性校验、图片-only 消息保留
- reasoning 原文本与普通 UI 分离；统一 Markdown 渲染
- 错误文案与诊断分离；错误记录脱敏
- 暂停 Agent 工具执行，保留助手、人设、会话与旧数据
- 搜索/深度思考迁移到统一输入区
- 云端 TTS 失败可见、WAV 头修复、按计费字符截断
- 导航与空入口收敛：移除发现占位页，接通关于页，清理静态伪入口

已完成（有测试证据）：消息树、提示词 role/图片、错误映射、TTS 计费截断与 WAV 头共 23 项 JVM 单元测试。
未完成（如实记录）：真机截图、TalkBack、IME 组合态、360dp/1.3x 字号矩阵 **NOT RUN**（设备能力限制）。

## v0.4.1（体验验收与补齐）

- 自动化回归补齐 ViewModel / Compose UI 层（需要 Android 测试运行时）
- TalkBack、IME、360dp、1.3x/2.0x 字号、手势/三键导航真机验证
- 性能与低端设备流畅度检查（流式刷新节流、图片解码）
- 用户真机反馈的交互缺陷修复

## v0.5.0（多模型管理完善）

- 服务商/模型配置易用性
- 模型能力识别与连接诊断
- 多模型切换与会话级模型绑定体验
- 搜索服务配置诊断

## v0.6.0（数据体系完善）

- 备份恢复与数据迁移体验
- 附件管理与存储占用
- 记忆分类、编辑、停用与清理
- 错误记录导出与诊断

## 长期探索（不进入近期承诺）

- Agent 自主工具执行重新评估（需要明确的权限模型与用户理解成本）
- MCP 工具调用
- 代码型插件执行沙箱
- 插件市场或云端发现（不建设虚构市场）
- 跨设备同步（可选，本地优先）
- 更多模型协议适配

## 不做

- 自研基础模型或模型托管平台
- 必须依赖官方云端账号/数据库/运营服务器才能使用
- 追逐每家模型官方 UI 的皮肤集合
- 功能入口很多但大量处于「规划中」或点击无反应的功能展厅
