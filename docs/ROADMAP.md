# 路线图

## 第一版（已完成）

核心聊天、模型适配、智能体管理、本地存储、同舟备份、插件框架、MCP 基础、Agent 实验框架、DeepSeek 搜索、项目文档与交付。

## 第二版（规划）

### 官方插件

- 朋友圈：动态发布、浏览与通知（复用统一通知系统）
- 表情包：管理、发送与插件数据空间
- 桌宠：独立渲染与交互

### 扩展能力

- 代码型插件执行环境与安全评估（沙箱、权限隔离）
- MCP 工具调用接入 Agent
- 角色卡/预设插件的完整生态（导入、分享）

### Agent

- 写操作工具（逐次确认、可撤销）
- 多步任务的取消与恢复
- 更细的权限矩阵（按工具授权）

### 工程

- release 签名与正式分发
- 多设备兼容性测试
- 数据库迁移自动化测试
- 单 HTML 演示文件（如需）

## 长期

- 插件市场/发现页（不要求项目方运营服务器）
- 跨设备同步（可选，本地优先）
- 更多模型协议适配
