## 6. 验收限制说明

- 本机容器无法启动 Android 模拟器，DSHA 无障碍通道返回 `ACCESSIBILITY_UNAVAILABLE`，设备 shell 返回 `DEVICE_CHANNEL_UNAVAILABLE`；
- 因此凡涉及动态界面、音频输出、输入法、读屏的验收，均如实标记 `NOT RUN`；
- 2026-11-15 用户录屏结论已纳入 `docs/附录_百川_v0.3.1_源码与录屏专项审查报告.md`，用于定位 v0.4.0 缺陷，不作为 v0.4.0 的验收结果。

## 7. 待用户真机确认的优先项

1. 发送 → 停止 → 再发送，状态是否互斥；
2. 删除一条 user 消息后继续发送，是否还会出现 English role 错误；
3. 图片-only 发送后，模型是否能看到图片；
4. Markdown 气泡、代码块横滚、链接点击；
5. 云端 TTS 配置后就绪提示与朗读效果；
6. 深色主题、窄屏、字号放大下的输入区与列表。
