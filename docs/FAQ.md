# 常见问题

## 模型配置

**Q：支持哪些模型服务？**
A：任何 OpenAI 兼容协议的服务（DeepSeek 官方、OpenAI 及多数第三方中转）。OP 协议目前仅预留入口。

**Q：API Key 安全吗？**
A：Key 使用 Android Keystore 加密保存，不写日志、不进普通备份；界面只显示密文。

**Q：为什么温度设置没效果？**
A：DeepSeek 思考模式下温度参数不生效（官方限制）。关闭「深度思考」后温度才可用。

## 聊天

**Q：编辑消息会覆盖原对话吗？**
A：不会。编辑与重新生成会创建分支，原对话保留，可通过分支切换器切回。

**Q：为什么看不到模型的思考过程？**
A：v0.4.0 起普通界面只显示「思考中…／已思考（用时 N 秒）」，不展示原始 reasoning 文本，避免内部推理与提示词内容泄露。

**Q：附件存在哪？**
A：应用私有目录，数据库只存相对路径。备份时随附件一起迁移。

## 数据与备份

**Q：换手机怎么迁移？**
A：我的 → 同舟备份 → 导出（ZIP 或文件夹），在新设备导入。API Key 需要重新填写。

**Q：选择性导入会怎样？**
A：只恢复所选类别，其他数据保留。跨类别引用可能不一致，建议全量导入。

## 插件

**Q：插件安全吗？**
A：插件在独立目录运行，启用前会列出权限并由你确认；插件异常不影响主聊天。代码型插件当前不执行。

**Q：为什么安装插件失败？**
A：检查 manifest 是否完整、API 版本是否兼容（当前 1.0）。

## 朗读

**Q：为什么云端朗读没有声音？**
A：云端朗读需要：① 在外观页开启「云端朗读」；② 已添加 DeepSeek 服务商并填写有效 API Key。任一条件不满足时会自动回退系统朗读，并在聊天页提示原因。

**Q：长文章朗读会失败吗？**
A：单次朗读按计费字符截断（汉字按 2 个字符、上限 10000），超出部分不会朗读，可分段使用。

## Agent

**Q：Agent 功能去哪了？**
A：v0.4.0 暂停了 Agent 自主工具执行与相关实验入口。助手、人设、会话和旧数据仍然保留；普通聊天不受影响。未来是否重新开放将在后续版本单独评估。

**Q：旧版本授予过 Agent 权限，升级后会自动执行吗？**
A：不会。服务层有全局开关，旧授权与旧 `agentMode` 都不能启动工具调用。

## 其他

**Q：为什么安装包是 debug 签名？**
A：第一版为调试交付，正式分发前会配置 release 签名。
