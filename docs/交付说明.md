## 三、已知问题与限制

1. Agent 工具仅三个只读工具（time_now、data_count_agents、data_count_messages），写操作工具未接入，需逐个补确认流程。
2. Agent 闭环为非流式，界面显示「正在调用工具…」后一次给出结果。
3. 撤销 Agent 授权后，进行中的任务不会自动取消。
4. 代码型插件不执行，仅登记状态并提示需要安全评估。
5. MCP 仅支持 initialize 与 tools/list，工具调用未接入。
6. 备份恢复选择性导入可能出现跨类别引用不一致（界面已提示建议全量导入）。
7. 正式发布需配置 release 签名与混淆验证，当前交付为 debug 签名。
8. 单 HTML 测试文件按发起者要求取消，改为 APK 真机验收。

## 四、安装与升级
