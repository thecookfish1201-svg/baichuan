# 阶段二（核心聊天）验收清单

> 验收人：项目发起者。需要准备一个可用的模型 API（DeepSeek 官方或其他 OpenAI 兼容服务）。

## 一、模型配置

- [ ] 「管理 → 相关配置」进入模型配置，点右上角添加服务商。
- [ ] 填写名称、API 地址、API Key，点「测试连接」显示成功。
- [ ] 点「获取模型列表」，能看到模型清单；保存后回到列表。
- [ ] 重新进入编辑，API Key 显示为密文，数据库文件中搜不到明文 Key。
- [ ] 使用错误的 Key 测试连接，提示「认证失败，请检查 API Key」。

## 二、智能体

- [ ] 消息页右上角「+」新建智能体，填写名称、人设、系统提示词，选择模型后保存。
- [ ] 消息页出现该智能体，点击进入聊天。
- [ ] 「管理 → 智能体」能看到列表，点击可编辑。

## 三、聊天

- [ ] 发送消息后，回复逐字流式显示。
- [ ] 生成过程中点「停止」，消息保留已生成内容，状态正确。
- [ ] 长按自己的消息 →「编辑并重发」，生成新分支，旧对话不被覆盖。
- [ ] 长按回复 →「重新生成」，出现分支切换器（‹ 1/2 ›），左右切换能切回旧分支。
- [ ] 长按消息 →「删除」，消息消失。
- [ ] 未配置模型时发送消息，出现「未配置模型」提示，不崩溃。
- [ ] 断网发送，出现网络错误提示，应用不崩溃。

## 四、安全与规范

- [ ] API Key 在数据库、日志中均无明文。
- [ ] 界面无 Emoji 充当图标。
- [ ] 深色模式下聊天气泡对比度正常。
- [ ] 系统字体放大后气泡文字不截断。

## 五、交付物

- [ ] APK 已安装并能完成上述路径。
- [ ] 《计划.md》已同步阶段二状态。
