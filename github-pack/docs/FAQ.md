# 常见问题

## 模型配置

**Q：支持哪些模型服务？**
A：任何 OpenAI 兼容协议的服务（DeepSeek 官方、OpenAI 及多数第三方中转）。OP 协议目前仅预留入口。

**Q：API Key 安全吗？**
A：Key 使用 Android Keystore 加密保存，不写日志、不进普通备份；界面只显示密文。

**Q：为什么温度设置没效果？**
A：DeepSeek 思考模式下温度参数不生效（官方限制）。关闭「深度思考」后温度才可用。

## 聊天

**Q：编辑消息会覆盖原对话吗？**
A：不会。编辑与重新生成会创建分支，原对话保留，可通过分支切换器切回。

**Q：思考链为什么不显示？**
A：只有服务端返回 `reasoning_content` 时才会显示。第三方中转可能剥离该字段。

**Q：附件存在哪？**
A：应用私有目录，数据库只存相对路径。备份时随附件一起迁移。

## 数据与备份

**Q：换手机怎么迁移？**
A：我的 → 同舟备份 → 导出（ZIP 或文件夹），在新设备导入。API Key 需要重新填写。

**Q：选择性导入会怎样？**
A：只恢复所选类别，其他数据保留。跨类别引用可能不一致，建议全量导入。

## 插件

**Q：插件安全吗？**
A：插件在独立目录运行，启用前会列出权限并由你确认；插件异常不影响主聊天。代码型插件当前不执行。

**Q：为什么安装插件失败？**
A：检查 manifest 是否完整、API 版本是否兼容（当前 1.0）。

## Agent

**Q：Agent 怎么开启？**
A：管理 → 智能体 → 编辑 → Agent 权限 → 授予，阅读免责说明并等待 10 秒后确认。

**Q：Agent 会自己执行危险操作吗？**
A：不会。Agent 只能调用注册的受控工具，且当前工具均为只读低风险工具；高风险操作需要额外确认机制，尚未接入。

**Q：运行记录在哪看？**
A：我的 → Agent 运行记录。

## 其他

**Q：为什么安装包是 debug 签名？**
A：第一版为调试交付，正式分发前会配置 release 签名。
