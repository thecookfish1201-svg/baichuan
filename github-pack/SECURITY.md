# 安全政策

## 报告漏洞

请不要在公开 Issue 中披露安全漏洞。请通过以下方式私下联系维护者：

- 邮箱：`<security@example.com>`（占位，发布前替换）

请在报告中包含：影响版本、复现步骤、影响范围、可能的修复建议。

我们会在确认后尽快回复，并在修复完成后致谢（如你愿意署名）。

## 安全设计要点

- API Key 使用 Android Keystore AES-GCM 加密存储，不落明文、不写日志、不进普通备份。
- 插件拥有独立数据空间，插件异常不影响主聊天。
- Agent 只能调用注册的受控工具，按智能体授权，未授权在服务层拒绝。
- Agent 系统操作遵循 Android 原生授权，不绕过系统权限。
- 备份文件包含 SHA-256 校验，导入前逐项验证。
